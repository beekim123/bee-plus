## pnpm 配置

### `pnpm-workspace.yaml`

**位置：** 根目录  
**作用：** 定义 pnpm 工作区，管理 monorepo 的包

```yaml
packages:
  - packages/*          # packages 下的所有子目录
  - documents          # 文档目录
  - usedemo/demo-proj  # Demo 项目
  - "!**/test/**"     # 排除测试目录
```

**关键点：**
- 所有在这里声明的目录都会被视为独立的包
- 可以使用通配符 `*` 匹配多个包
- 使用 `!` 排除不需要的目录

## TypeScript 配置

### `tsconfig.json` （根配置）

**位置：** 根目录  
**作用：** TypeScript 项目引用根配置

```json
{
  "files": [],
  "references": [
    { "path": "./tsconfig.node.json" },
    { "path": "./tsconfig.app.json" }
  ]
}
```

**说明：**
- 使用 TypeScript 项目引用（Project References）
- 不直接包含文件，而是引用其他配置
- 实现配置分离和增量编译

---

### `tsconfig.node.json` （Node 环境配置）

**位置：** 根目录  
**作用：** 配置 Node.js 环境的 TypeScript（用于 Vite 配置等）

```json
{
  "extends": "@tsconfig/node24/tsconfig.json",
  "include": [
    "vite.config.*",
    "vitest.config.*",
    "cypress.config.*",
    "nightwatch.conf.*",
    "playwright.config.*"
  ],
  "compilerOptions": {
    "composite": true,
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "types": ["node"]
  }
}
```

**关键配置：**
- `extends: "@tsconfig/node24/tsconfig.json"` - 继承 Node 24 推荐配置（适配 Node 22）
- `composite: true` - 启用项目引用
- `module: "ESNext"` - 使用最新的 ES 模块
- `moduleResolution: "Bundler"` - 使用打包器的模块解析策略

**为什么是 node24？**
- Node 22 对应使用 `@tsconfig/node24` 包
- 提供适合 Node 22 的 TypeScript 编译选项

---

### `tsconfig.app.json` （应用配置）

**位置：** 根目录  
**作用：** 配置应用和组件的 TypeScript

```json
{
  "extends": "@vue/tsconfig/tsconfig.dom.json",
  "include": [
    "packages/components/**/*.ts",
    "packages/components/**/*.vue"
  ],
  "exclude": ["src/**/__tests__/*"],
  "compilerOptions": {
    "composite": true,
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

**关键配置：**
- `extends: "@vue/tsconfig/tsconfig.dom.json"` - 继承 Vue 官方推荐配置
- `include` - 包含组件库的所有 TS 和 Vue 文件
- `paths` - 设置路径别名（`@` 指向 `src`）

---

### `usedemo/demo-proj/tsconfig.json` （Demo 项目配置）

**位置：** `usedemo/demo-proj/`  
**作用：** Demo 项目的 TypeScript 配置

```json
{
  "extends": "../../tsconfig.json",
  "include": [
    "env.d.ts",
    "src/**/*",
    "src/**/*.vue"
  ],
  "compilerOptions": {
    "module": "NodeNext",
    "moduleResolution": "NodeNext"
  }
}
```

**关键配置：**
- `extends: "../../tsconfig.json"` - 继承根配置
- `module: "NodeNext"` - 使用 Node.js 的 ES 模块解析
- `moduleResolution: "NodeNext"` - 使用 Node.js 的模块解析策略

**注意：**
- 这个配置要求导入时使用 `.js` 扩展名（即使是 `.ts` 文件）
- 例如：`import { xxx } from './button/index.js'`

## Package.json 配置

### 根目录 `package.json`

**位置：** 根目录  
**作用：** 管理整个 monorepo 的依赖和脚本

```json
{
  "name": "bee-plus",
  "version": "1.0.0",
  "description": "A simple Vue3 + TypeScript components library",
  "scripts": {
    "dev": "pnpm -C usedemo/demo-proj dev"
  },
  "devDependencies": {
    "@tsconfig/node24": "^24.0.3",
    "@vue/tsconfig": "^0.4.0",
    "sass": "^1.65.1",
    "typescript": "^5.1.6"
  },
  "dependencies": {
    "@bee-plus/components": "workspace:^",
    "@bee-plus/theme-chalk": "workspace:^",
    "@bee-plus/utils": "workspace:^",
    "vue": "^3.3.4"
  }
}
```

**关键配置：**
- `workspace:^` - 引用工作区内的包（pnpm 特性）
- `"dev": "pnpm -C usedemo/demo-proj dev"` - `-C` 指定在子目录执行命令

**位置：** `packages/components/`  
**作用：** 组件包配置

```json
{
  "name": "@bee-plus/components",

  "type": "module",
  "main": "index.ts",
```

**关键配置：**

- `"main": "index.ts"` - 包的入口文件

## Vite 配置

### `usedemo/demo-proj/vite.config.ts`

**位置：** `usedemo/demo-proj/`  
**作用：** Vite 开发服务器和构建配置

```typescript
import { fileURLToPath, URL } from 'node:url'
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import vueDevTools from 'vite-plugin-vue-devtools'

export default defineConfig({
  plugins: [
    vue(),
    vueDevTools(),
  ],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    },
  },
})
```

**关键配置：**
- `plugins: [vue()]` - 支持 Vue 3 单文件组件
- `vueDevTools()` - Vue 开发者工具集成
- `alias: { '@': './src' }` - 路径别名设置

## 💡 常见配置修改

### 添加新的工作区包

修改 `pnpm-workspace.yaml`：
```yaml
packages:
  - packages/*
  - my-new-package  # 新增
```

### 修改 Node 版本限制

修改 `usedemo/demo-proj/package.json`：
```json
{
  "engines": {
    "node": ">=22.12.0"  // 修改版本
  }
}
```

### 添加路径别名

修改 `tsconfig.app.json`：
```json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"],
      "@components/*": ["./packages/components/*"]  // 新增
    }
  }
}
```

## ⚠️ 注意事项

### 1. TypeScript 模块解析

- 根目录使用 `"moduleResolution": "Bundler"`
- Demo 项目使用 `"moduleResolution": "NodeNext"`
- 导入时需要加 `.js` 扩展名（即使源文件是 `.ts`）

### 2. Workspace 依赖版本

- `workspace:^` - 自动匹配版本号
- `workspace:*` - 总是使用最新版本
- 推荐使用 `workspace:*` 在开发阶段

### 3. 包的 type 字段

- 所有包都应设置 `"type": "module"`
- 确保使用 ES 模块而非 CommonJS
