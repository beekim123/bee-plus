## 项目简介

**Bee-Plus** 是一个基于 Vue 3 + TypeScript 的组件库，采用 Monorepo 架构，使用 pnpm workspace 进行包管理。

### 技术栈

- **框架：** Vue 3.x
- **语言：** TypeScript 5.x
- **构建工具：** Vite
- **包管理：** pnpm workspace
- **样式：** Sass

### 核心特性

- ✅ TypeScript 类型支持
- ✅ Monorepo 架构，模块化管理
- ✅ 支持按需引入
- ✅ 完整的开发环境和示例项目

## 项目结构详解

### 1. `packages/components` - 组件包

#### 目录结构
```
packages/components/
├── index.ts           # 组件库主入口（导出所有组件）
├── package.json       # 包配置
└── button/            # Button 组件
    ├── index.ts       # 组件入口（使用 withInstall 包装）
    └── src/
        └── button.vue # 组件实现
```

#### `index.ts` - 组件库主入口
```typescript
// Main entry point for @bee-plus/components
export { default as BeeButton } from './button/index.js'
```

**作用：** 统一导出所有组件，供外部项目使用。

#### `button/index.ts` - 组件入口
```typescript
import Button from "./src/button.vue";
import { withInstall } from "@bee-plus/utils";

export default withInstall(Button);
```

**作用：** 使用 `withInstall` 工具函数为组件添加全局注册能力。

---

### 2. `packages/utils` - 工具包

#### 目录结构
```
packages/utils/
├── index.ts           # 工具包入口
├── with-install.ts    # 组件安装工具
└── package.json
```

#### `with-install.ts`
提供 `withInstall` 函数，为 Vue 组件添加 `install` 方法，使其可以通过 `app.use()` 全局注册。

---

### 3. `packages/theme-chalk` - 样式包

用于存放组件的样式文件（Sass/CSS），当前为空，待后续开发。

---

### 4. `usedemo/demo-proj` - 示例项目

一个完整的 Vue 3 项目，用于测试和演示组件库的使用。

#### 关键文件
- `src/main.ts` - 应用入口，引入并注册组件
- `src/views/HomeView.vue` - 演示页面

## 配置文件说明

### 1. `pnpm-workspace.yaml`

```yaml
packages:
  - packages/*
  - documents
  - usedemo/demo-proj
  - "!**/test/**"
```

**作用：** 定义 pnpm 工作区，指定哪些目录是独立的包。

---

### 2. TypeScript 配置

#### `tsconfig.json` - 根配置
```json
{
  "files": [],
  "references": [
    { "path": "./tsconfig.node.json" },
    { "path": "./tsconfig.app.json" }
  ]
}
```

**作用：** 使用 TypeScript 项目引用模式，分离不同类型的配置。

#### `tsconfig.node.json` - Node 环境配置
```json
{
  "extends": "@tsconfig/node24/tsconfig.json",
  "include": [
    "vite.config.*",
    "vitest.config.*",
    "cypress.config.*",
    "nightwatch.conf.*",
    "playwright.config.*"
  ],
  "compilerOptions": {
    "composite": true,
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "types": ["node"]
  }
}
```

**作用：** 
- 继承 `@tsconfig/node24` 的推荐配置（适配 Node 22）
- 用于配置文件（如 `vite.config.ts`）

#### `tsconfig.app.json` - 应用配置
```json
{
  "extends": "@vue/tsconfig/tsconfig.dom.json",
  "include": [
    "packages/components/**/*.ts",
    "packages/components/**/*.vue"
  ],
  "exclude": ["src/**/__tests__/*"],
  "compilerOptions": {
    "composite": true,
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

**作用：** 
- 继承 Vue 官方推荐的 DOM 环境配置
- 配置组件包的类型检查

---

### 3. `package.json` 配置

#### 根目录 `package.json`

```json
{
  "name": "bee-plus",
  "version": "1.0.0",
  "description": "A simple Vue3 + TypeScript components library",
  "scripts": {
    "dev": "pnpm -C usedemo/demo-proj dev"
  },
  "devDependencies": {
    "@tsconfig/node24": "^24.0.3",
    "@vue/tsconfig": "^0.4.0",
    "sass": "^1.65.1",
    "typescript": "^5.1.6"
  },
  "dependencies": {
    "@bee-plus/components": "workspace:^",
    "@bee-plus/theme-chalk": "workspace:^",
    "@bee-plus/utils": "workspace:^",
    "vue": "^3.3.4"
  }
}
```

**关键点：**
- `workspace:^` 表示使用 pnpm workspace 的包
- 开发依赖统一在根目录管理

#### `packages/components/package.json`

```json
{
  "name": "@bee-plus/components",
  "version": "1.0.0",
  "description": "Vue 3 component library for bee-plus",
  "type": "module",
  "main": "index.ts",
  "types": "index.ts"
}
```

**关键配置：**
- `"type": "module"` - 使用 ES Module
- `"main": "index.ts"` - 指定入口文件
- `"types": "index.ts"` - 指定类型定义文件

#### `usedemo/demo-proj/package.json`

```json
{
  "name": "demo-proj",
  "type": "module",
  "engines": {
    "node": "^20.19.0 || >=22.12.0"
  },
  "dependencies": {
    "@bee-plus/components": "workspace:*",
    "@bee-plus/utils": "workspace:*",
    "vue": "^3.5.26",
    "vue-router": "^4.6.4"
  }
}
```

**关键点：**
- 使用 `workspace:*` 引用本地工作区的包
- 限定 Node 版本要求

## 开发指南

### 添加新组件

假设要添加一个 `Input` 组件：

#### 1. 创建组件目录
```bash
mkdir -p packages/components/input/src
```

#### 2. 创建组件文件
`packages/components/input/src/input.vue`
```vue
<template>
  <input :value="modelValue" @input="handleInput" />
</template>

<script lang="ts" setup>
defineProps<{
  modelValue: string
}>()

const emit = defineEmits<{
  'update:modelValue': [value: string]
}>()

const handleInput = (e: Event) => {
  emit('update:modelValue', (e.target as HTMLInputElement).value)
}
</script>
```

#### 3. 创建组件入口
`packages/components/input/index.ts`
```typescript
import Input from "./src/input.vue";
import { withInstall } from "@bee-plus/utils";

export default withInstall(Input);
```

#### 4. 在主入口导出
修改 `packages/components/index.ts`：
```typescript
export { default as BeeButton } from './button/index.js'
export { default as BeeInput } from './input/index.js'  // 新增
```

#### 5. 在示例项目中使用
`usedemo/demo-proj/src/main.ts`
```typescript
import { BeeButton, BeeInput } from '@bee-plus/components'

app.use(BeeButton)
app.use(BeeInput)
```

## 使用组件

### 方式 1：全局注册（推荐用于 Demo）

```typescript
// main.ts
import { createApp } from 'vue'
import { BeeButton } from '@bee-plus/components'
import App from './App.vue'

const app = createApp(App)
app.use(BeeButton)  // 全局注册
app.mount('#app')
```

```vue
<!-- 使用 -->
<template>
  <BeeButton>点击我</BeeButton>
</template>
```

### 方式 2：局部导入（推荐用于生产）

```vue
<script setup lang="ts">
import { BeeButton } from '@bee-plus/components'
</script>

<template>
  <BeeButton>点击我</BeeButton>
</template>
```

## 常见问题

### 1. 模块找不到错误

**错误信息：**
```
找不到模块"@bee-plus/components"或其相应的类型声明
```

**解决方案：**
- 确保在 `package.json` 中添加了依赖：
  ```bash
  pnpm add '@bee-plus/components@workspace:*'
  ```
- 检查 `pnpm-workspace.yaml` 配置是否正确

### 2. TypeScript 配置错误

**错误信息：**
```
failed to resolve "extends":"@tsconfig/node18/tsconfig.json"
```

**解决方案：**
- 确保安装了正确的 tsconfig 依赖：
  ```bash
  pnpm add -D -w @tsconfig/node24
  ```
- 将 `tsconfig.node.json` 中的 `extends` 改为 `@tsconfig/node24/tsconfig.json`

### 3. 组件未显示

**检查列表：**
1. 确认组件已在 `packages/components/index.ts` 中导出
2. 确认在 `main.ts` 中正确导入和注册
3. 检查浏览器控制台是否有错误
4. 确保 dev server 正在运行
