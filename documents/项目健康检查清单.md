## 🐛 常见问题排查

### 问题 1: 模块找不到

**错误示例：**
```
找不到模块"@bee-plus/components"或其相应的类型声明
```

**排查步骤：**

1. **检查 pnpm-workspace.yaml**
   ```yaml
   packages:
     - packages/*
     - usedemo/demo-proj
   ```

2. **检查包的 package.json**
   ```bash
   cat packages/components/package.json
   ```
   确认有：
   - `"name": "@bee-plus/components"`
   - `"type": "module"`
   - `"main": "index.ts"`

3. **检查使用方的 package.json**
   ```bash
   cat usedemo/demo-proj/package.json
   ```
   确认 dependencies 中有：
   ```json
   "@bee-plus/components": "workspace:*"
   ```

4. **重新链接依赖**
   ```bash
   pnpm install
   ```

---

### 问题 2: TypeScript 编译错误

**错误示例：**
```
Relative import paths need explicit file extensions in ECMAScript imports
```

**原因：**
- `moduleResolution: "NodeNext"` 要求显式扩展名

**解决方案：**
```typescript
// ❌ 错误
import { BeeButton } from './button/index'

// ✅ 正确
import { BeeButton } from './button/index.js'
```

---

### 问题 3: 组件注册失败

**症状：**
- 组件在模板中使用时报错："Unknown custom element"

**排查步骤：**

1. **检查组件是否导出**
   ```typescript
   // packages/components/index.ts
   export { default as BeeButton } from './button/index.js'
   ```

2. **检查组件是否使用 withInstall**
   ```typescript
   // packages/components/button/index.ts
   import Button from "./src/button.vue";
   import { withInstall } from "@bee-plus/utils";
   export default withInstall(Button);
   ```

3. **检查是否正确注册**
   ```typescript
   // main.ts
   import { BeeButton } from '@bee-plus/components'
   app.use(BeeButton)
   ```

---

### 问题 4: 热更新不生效

**症状：**
- 修改代码后浏览器不自动刷新

**排查步骤：**

1. **检查 Vite 配置**
   ```typescript
   // vite.config.ts 应该有
   export default defineConfig({
     plugins: [vue()],
   })
   ```

2. **检查文件是否在 include 范围内**
   ```json
   // tsconfig.app.json
   {
     "include": [
       "packages/components/**/*.ts",
       "packages/components/**/*.vue"
     ]
   }
   ```

3. **重启开发服务器**
   ```bash
   # Ctrl+C 停止
   pnpm run dev
   ```

### 更新 Node 版本后的操作

1. **更新 tsconfig 依赖**
   ```bash
   # 例如升级到 Node 24
   pnpm add -D -w @tsconfig/node24
   ```

2. **更新 tsconfig.node.json**
   ```json
   {
     "extends": "@tsconfig/node24/tsconfig.json"
   }
   ```

3. **更新 package.json engines**
   ```json
   {
     "engines": {
       "node": ">=24.0.0"
     }
   }
   ```

## 🚨 已知限制和注意事项

### 1. Vite Beta 版本

**问题：** 使用 Vite beta 版本导致 peer dependencies 警告

**状态：** 可接受，不影响开发

**警告示例：**
```
✕ unmet peer vite@"^6.0.0 || ^7.0.0-0": found 8.0.0-beta.7
```

**解决方案：** 等待 Vite 8 正式发布，或降级到 Vite 6/7

---

### 2. 导入扩展名

**问题：** 必须写 `.js` 扩展名而不是 `.ts`

**原因：** `moduleResolution: "NodeNext"` 的要求

**示例：**
```typescript
// 即使源文件是 index.ts，也要写 .js
import { xxx } from './button/index.js'
```
